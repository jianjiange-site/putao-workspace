# 面试学习文档模板

## 目录结构

每次学习创建一个独立目录：

```
doc/course/<YYYY-MM-DD>-<模块名>/
├── README.md           # 索引
├── prd.md             # 业务功能文档（类PRD）
├── knowledge.md        # 知识点整理
└── interview-qa.md    # 面试问答
```

---

```markdown

- [核心知识点](./knowledge.md) - 技术原理、权衡取舍
- [面试问答](./interview-qa.md) - 高频问题、追问准备

## 学习目标

- [ ] 理解 XX 业务全貌

- 设计文档：`doc/specs/<service>-design.md`
- 核心代码：`dating-server/<service>/src/main/java/...`
```

## 面试话术模板

### 介绍项目
```
"我在实习期间主要负责 XX 服务，这个服务主要做 XXX。"

"我遇到的最大挑战是 XXX，当时想了几个方案，最终选了 XXX 方案，原因是 XXX。"
```

### 讲技术选型
```
"我们当时面临 XXX 问题，有 A、B 两种方案。"

"A 方案的优点是 XXX，但缺点是 XXX。"

"B 方案正好相反。"

"综合考虑 XXX 因素（qps、数据量、团队能力等），我们选择了 A 方案。"
```

### 讲问题排查
```
"当时遇到了 XXX 问题，我先是 XXX 排查，发现是 XXX 原因导致的。"

"后来通过 XXX 方法解决了这个问题。"
```

### 讲个人贡献
```
"这部分功能主要是我负责的。"

"当时我调研了 XXX 方案，最终落地了 XXX。"
```
